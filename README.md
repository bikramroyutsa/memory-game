# memory-game
A memory card game using React. This project fetches top 25 anime characters data from myAnimeList API and displays their images as cards.
The player has to select different cards each time. If they choose the same card twice, they lose. The game has 3 levels of difficulty.

Live preview: https://memory-game-anime-characters.vercel.app/
